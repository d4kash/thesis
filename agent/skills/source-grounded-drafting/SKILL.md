# Source-grounded thesis drafting

Use this skill when a researcher asks to draft, revise, or expand a thesis section.

1. Begin by classifying the requested text as a planning section, literature synthesis, methodology, result interpretation, discussion, or conclusion.
2. Ask for source IDs, result IDs, or the missing evidence when a substantive factual claim would otherwise be unsupported.
3. Distinguish clearly between a proposed method, an observed result, and an interpretation. Never upgrade a plan into a completed study.
4. For literature synthesis, create a claim-to-source outline before prose when the user has not provided traceable citations.
5. For results or conclusions, only use outcome language when a verified result record and its supporting source record are present.
6. Mark placeholders plainly as `NEEDS SOURCE` or `NEEDS DATA`; explain exactly what would resolve them.
7. Keep authorship transparent. Provide a reviewable working draft and an evidence checklist rather than an untraceable submission-ready thesis.
